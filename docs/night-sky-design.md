# 밤하늘 통합 메뉴

## 화면과 이동

- 공통 메뉴의 달력·행성을 `밤하늘` 하나로 묶고 `오늘 밤`을 기본 탭으로 연다. `천문 일정`에서 기존 달력과 필터를 사용한다.
- 홈의 첫 버튼은 `오늘 밤 하늘 보기`, 두 번째 버튼은 `자유게시판 둘러보기`다.
- 홈의 기존 성운 AVIF/WebP 자산을 짧은 헤더에 재사용한다. 본문 지도와 일정 카드는 단색으로 유지한다.
- 행성 관측지 아래에 실제 달력 데이터의 가장 가까운 일정을 표시한다. 기간 시작·종료와 한국 날짜 경계에서 갱신하며, 국내 관측 가능 여부를 함께 안내한다.
- 우주 이야기 안내는 도구 아래에 놓는다. 게시판에서는 밤하늘 헤더와 탭이 숨겨진다.

## 호환성과 접근성

- 기존 `main.html#planets`, `main.html#sky`, `main.html#lounge` 및 독립 `planets.html`, `sky.html` 주소를 보존한다.
- 탭은 일반 링크에서 점진적으로 탭 역할로 확장한다. 좌우 화살표·Home·End·Space와 브라우저 뒤로/앞으로 이동을 지원한다. 새 탭이나 JavaScript 비활성 상태에서는 독립 도구로 이동한다.
- iframe 내부의 일정/행성 링크는 활성 프레임과 동일 출처를 확인해 상위 탭을 전환한다. 다른 페이지에 삽입하면 일반 링크로 동작한다.
- 기존 행성 계산과 일정 값, 분석 도구 식별값은 유지한다. 달력은 선택할 때 처음 불러온다.
- 일정 스크립트가 없어도 행성 지도는 동작한다. 달력에는 실패 안내를 표시하고 달 정보·행성 이동을 유지하며, 준비 완료로 기록하지 않는다.

## 검증

- 로컬 모의 서버에서 통합 탭, 직접 주소, 새로고침, 뒤로/앞으로, 키보드, 독립·삽입 화면, JavaScript 비활성, 일정 파일 누락을 확인한다. 운영 서버에 테스트 데이터를 쓰지 않는다.
- 320·390·861·1440px에서 가로 넘침과 중복 헤더가 없는지 검사한다. 실제 글꼴과 배경을 불러온 데스크톱·모바일 화면도 검토한다.
- 공통 메뉴 생성 일치, 기존 게시판·홈·뉴스·분석·이야기 검사와 천문 시간 경계 검사를 실행한다.

## 데이터 관리

일정은 기존과 같은 수동 편집 데이터이며 마지막 항목은 2027년 8월 2일이다. 새 일정을 추가할 때는 `sky-events.js`를 갱신한다. 일정이 소진되면 다음 일정 준비 안내를 표시하며 계산 기반 행성 지도는 계속 사용할 수 있다.
