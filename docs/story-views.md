# 우주 이야기 조회수와 아침 브리핑

운영자의 2026-10-07 요청으로 제목별 조회수와 많이 열어 본 이야기를 Gmail 아침 브리핑에 추가합니다. 기존 사이트 방문 건수나 퍼널의 최초 진입 수를 이야기 조회수로 바꾸어 쓰지 않습니다. 이전 계측에는 개별 글이 구분되지 않거나 같은 세션의 두 번째 글이 빠지는 경우가 있어 새 집계 이전 조회수는 복원하지 않습니다.

## 집계 단위

- 공개 이야기 상세 화면이 보이고 기존 사용 분석의 세션·제외 조건을 만족하면 글마다 세션당 한 번 집계합니다. 새로고침·뒤로가기는 중복 제외하며 다른 이야기는 각각 집계합니다.
- 기존 무작위 탭 세션을 재사용합니다. 30분 비활동 또는 한국 날짜 변경 후 새 세션입니다. 기기 ID·계정 ID·인증 토큰·제목·URL·검색 매개변수는 이 요청에 넣지 않습니다.
- 조회수는 사람이 읽은 수나 완독 수가 아닙니다. 새 탭·브라우저 복원·저장소 제한·봇 판별 및 전송 실패의 영향이 있습니다. 운영자·자동 검사·명백한 봇·숨겨진 문서·외부 임베드는 기존 정책대로 제외합니다.
- 기존 `feature_view`와 퍼널 보고의 의미는 유지합니다. 이 별도 조회 집계는 관리자 Gmail 보고용이며 공개 조회수 위젯을 추가하지 않습니다.

## 저장과 권한

`record_story_view(p_story_id, p_session_id)`는 등록된 공개 글만 받는 쓰기 전용 RPC입니다. 실제 페이지의 `data-orbit-story-id`와 경로가 일치해야 브라우저가 전송합니다. 원본 세션 식별자는 새 이야기 테이블에 저장하지 않고 글·한국 날짜·세션을 해시한 단기 중복 방지 토큰만 사용합니다. 이 토큰은 글과 날짜가 달라지면 달라집니다.

비공개 `orbit_story_private` 스키마의 `catalogue`는 공개 ID·발행일·집계 시작 시각, `daily`는 날짜·글 ID·조회 건수를 저장합니다. `recent_views`는 현재 및 전날 한국 날짜의 중복 방지 값만 유지하며 매시간 정리합니다. 최대 약 49시간 뒤 삭제되고 조회 요청 때도 오래된 값을 정리합니다. 식별자가 없는 일별 조회 숫자는 누적 비교를 위해 계속 보관합니다. 일반 이용자는 세 테이블을 읽거나 수정할 수 없습니다.

## 새 글 자동 등록

신규 migration 적용만으로 글이 등록되거나 과거 조회수가 생기지는 않습니다. 최초 등록 및 이후 이야기 자동화는 **발행·배포를 확인한 뒤** 최신 `_editorial/published.json`에 실제로 실린 ID와 발행일만 기존 승인된 Supabase 연결로 등록합니다. 새 API 키나 공개 관리자 기능을 만들지 않습니다.

```sql
insert into orbit_story_private.catalogue (story_id, published_on)
values ('ACTUAL_PUBLIC_STORY_ID', 'ACTUAL_PUBLICATION_DATE'::date)
on conflict (story_id) do nothing;
```

위 값은 설명용 자리표시자이며 실행 전 공개 발행 장부의 실제 값으로 바꿉니다. 등록 스크립트는 `scripts/story_views_catalogue.py --sql`입니다. 재등록해도 최초 `tracking_started_at`을 바꾸지 않습니다. 실제 등록에 성공하기 전 구간은 미집계입니다. 등록 실패는 발행 성공과 구분해 알리고 다음 실행에서 누락 ID만 다시 확인합니다. 미래 글이나 초안은 등록하지 않습니다.

## 브리핑

기존 아침 예약·본인 수신처·중복 발송 방지는 유지합니다. 브리핑 자동화는 [집계 SELECT](../supabase/story_views_report.sql)로 `catalogue`와 `daily`의 결과만 읽습니다. 역할 전환·권한 변경·쓰기·회원/세션 보고 RPC·중복 방지 토큰 조회는 하지 않습니다. 실제 결과는 운영자 Gmail에만 사용하고 저장소·예약 프롬프트에 저장하지 않습니다.

- 제목은 현재 발행 장부의 ID를 `_editorial/articles/<id>.json`의 `title`과 연결하고 공개 페이지를 링크합니다. 등록만 있고 공개 장부에 없는 ID는 순위에서 제외합니다.
- 한국 시간 어제를 마감일로 삼아 제목별 어제, 최근 7일, 집계 시작 이후 누적 조회수를 보여 줍니다. 오늘의 진행 중 수치는 섞지 않습니다.
- 최근 7일 조회수가 있는 상위 5편을 표시합니다. 동률은 어제 조회수, 누적 조회수, 공개 제목 순으로 정렬합니다. 조회수가 없으면 억지로 인기 순위를 만들지 않습니다. 어제 발행한 글은 제목과 어제 조회수를 함께 새 글 항목에 표시합니다.
- `not_started`·`not_published`는 0이 아니라 미집계/미발행입니다. `partial`은 집계 시작 시각과 부분 집계라는 표시를 붙입니다. 최초에는 7일치가 쌓이지 않았다고 명시합니다. `tracked`의 0은 기록된 조회 0건이며 실제 독자가 없었다는 단정은 하지 않습니다.
- 전주 같은 기간 비교는 양쪽 모두 `tracked`일 때만 계산합니다. 이전 값 0이면 백분율 대신 `0 → N회`를 씁니다. 새 글·집계 기간이 다른 글에 소급 조회수나 인기 상승률을 만들지 않습니다.
- 표 제목이나 각주에 `이야기별 세션 중복 제외 조회수 · 완독/사람 수 아님`을 적습니다. 수치·순위 변화도 기존 메일의 의미 있는 변화 판단에 포함합니다.
