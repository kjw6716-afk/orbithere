# 최소 실사용 퍼널 측정 명세

작성: 2026-09-27. 이벤트 구현 전에 정한 명세. 기준 main `92649bbcf62ac06874675ceed10c49bf9ac40df5`.
UI·메뉴·CTA baseline은 유지한다. 아래 수치는 사람 수가 아니라 명시된 관측 단위의 수이다.

## 지표 정의

모든 사이트 기간은 Asia/Seoul(KST) 날짜, `[시작일 00:00, 종료일 다음 날 00:00)`이다. 기본 비교는 오늘을 제외한 완결된 7일/28일. 오늘은 부분 집계로 표시한다. 전환율은 항상 `분자 / 분모 (율)`로 함께 표시하고 분모 0은 계산 불가이다. 기존 방문 카운터·세션·회원 수를 합산하지 않는다.

## 수집 계약 (8개 이벤트)

`record_funnel_event(p_event jsonb)`에 최대 512바이트 JSON 한 개. 키는 `session_id`, `event`, `feature`, `detail`, `context`, `sequence`, `page_key`, `audience`만 허용. UUID는 무작위 탭 세션 ID이고 회원 UUID를 사용하지 않는다. sequence는 세션 내 1~128의 발생 순서이며 시각은 서버가 부여한다.

feature: `home, planets, calendar, board, guide, stories, story, news, about, policy, other`.
context: `direct, embed`. audience: 세션 시작 시 영구 인증 회원 `member`, 그 외 `guest`; 이후 로그인 여부와 무관하게 시작 분류를 유지한다. 회원 ID는 저장하지 않는다.

page_key: `home, main_planets, main_calendar, main_board, planets, calendar, board, guide, reading_sky, stories, news, about, policy, terms, story_other, other` 또는 migration에 열거한 현재 공개 이야기 10개의 파일명 줄기. 승인된 공개 경로의 분류만 보내고 게시글 ID·URL/query/hash 원문은 전송하지 않는다. 새 이야기는 허용 목록 갱신 전까지 story_other이다. main 자체를 별도 중복 화면으로 세지 않는다. 약관·개인정보·관리자·오류·종료된 노트 페이지는 계측하지 않는다.

|event|발생 조건|detail|
|---|---|---|
|session_start|추적 가능한 탭의 첫 보이는 기능|google, naver, other_search, external, internal, unattributed|
|feature_view|실제로 표시한 페이지/패널, 기능당 세션 1회|none|
|tool_ready|보이는 행성·달력에 정상 정보 표시, 도구당 1회|none|
|tool_use|신뢰된 사용자 조작으로 도구 상태를 변경|planets: time, region / calendar: filter|
|board_enter|첫 게시판 표시/다른 기능에서 게시판으로 이동|직전 feature 또는 landing|
|write_start|새 글 버튼의 명시적 시작 또는 새 글 폼 입력, 세션 1회|explicit, input|
|auth_open|로그인/가입 화면 열기, 회원 프로필 화면 제외|login, signup|
|auth_attempt|인증 요청을 시작하는 명시적 동작|email_login, email_signup, google|

순수 렌더·resize·숨겨진 iframe·자동 복원은 실제 사용이 아니다. 동일 이벤트/기능/detail은 세션 내 중복 제거한다(글쓰기 시작은 detail과 무관하게 1회). 인증 화면/시도는 글쓰기 시작 전·후에 각각 한 번 허용해, 앞서 로그인에 실패한 사람이 글을 쓰고 다시 인증한 경로를 빠뜨리지 않는다. 서버의 sequence 유일 제약은 전송 재시도를 중복 제거한다. 게시·댓글·공감 성공과 auth_complete는 이벤트에 포함하지 않는다.

## 세션·출처·보존 결정

- sessionStorage의 탭 UUID. 새로고침/뒤로/앞으로/같은 메뉴는 세션을 늘리지 않는다. 의미 있는 사용자 활동이 30분 없거나 KST 날짜가 달라지면 다음 관측에서 새 UUID. 탭 종료 시 종료하며 종료 이벤트는 보내지 않는다. 탭 복제·브라우저 복원·저장소 제한으로 정확한 탭 경계가 달라질 수 있다.
- iframe은 상위 창 하나가 관리한다. 숨겨진 프레임은 수집하지 않는다. 세션 최초 출처는 내부 탐색으로 덮어쓰지 않는다. 새로 시작한 내부 페이지 유입은 internal로 표시한다.
- 같은 문서를 열어 둔 채 비활동/날짜 경계로 시작한 새 세션은 오래된 document.referrer를 검색 유입으로 재사용하지 않고 unattributed로 분류한다.
- analytics용 localStorage 지속 식별자·쿠키·익명 Auth 계정은 만들지 않는다. 기존 orbit_device_id를 analytics에 재사용하지 않는다. 비회원 1/7일 재방문은 성공 기준에서 제외한다.
- 세션 이벤트 원본 30일 경과 후 매일 정리(실행 간격만큼 최대 1일 지연), KST 집계 후 삭제. 장기 일별 집계에는 ID가 없으며 400일 후 삭제한다. 정리 RPC/cron을 migration과 함께 설치하고 실행 상태를 운영자가 확인한다.
- 원문 referrer/query, IP, UA, 이메일·닉네임·내용·위치·검색어·사진은 analytics에 저장하지 않는다. 웹/인증 제공자의 기본 접속 로그는 별도 기존 정책 대상이다.
- 인증 세션과 기여 DB를 연결하는 식별표를 만들지 않는다. 정확한 `인증 시작 → 인증 완료 → 첫 참여` 개인 전환율은 계산하지 않는다. 회원 UUID는 집계 쿼리 내부에서만 사용한다.
- 같은 탭에서 계정을 바꿔도 브라우저 관측 세션이라는 단위는 같다. 따라서 이벤트 간 연결을 같은 개인의 행동이라고 단정하지 않는다. 기존 회원·초안·댓글 권한 격리는 그대로 검증한다.
- 개인정보처리방침에 목적·수집값·세션 저장·삭제를 설명한다. 출시 전 운영자는 이 처리의 적법한 근거와 동의 필요성을 검토해야 한다. 지속 식별자/쿠키나 비회원 장기 추적 도입은 별도 법적 검토·결정 대상이다.

## 제외·실패·권한

localhost/다른 호스트, webdriver, 명백한 crawler UA, 명시적 `orbit_analytics_exclude=1`, 확인된 운영자 화면은 제외한다. UA는 브라우저 안에서만 판별하며 저장/전송하지 않는다. 로그인 전 운영자나 UA를 속인 봇 제외는 완벽하지 않다. 테스트는 모든 백엔드를 차단/모의하며 운영 검증은 방문 전에 제외 플래그를 설정한다. 기존 방문 카운터는 중복 구현하지 않는다.

수집은 비동기·제한된 단발 요청이며 오류는 조용히 버린다. 핵심 이동·글쓰기·인증은 기다리지 않는다. 로컬 이벤트 적재/무한 재시도 없음. DB 원본은 private schema와 RLS, 일반 역할에 SELECT/UPDATE/DELETE 미부여. 수집 RPC만 제한된 insert를 허용하고 search_path를 고정한다. 운영 집계/정리는 보호된 역할만 허용한다. 수집값은 제품 권한에 사용하지 않는다.

## 배포 경계

운영 DB에 적용하지 않은 추가형 migration을 PR로 먼저 검토한다. 승인 후 migration → 역할/입력/정리 검증 → 코드 merge → 해당 Pages SHA 및 파일 대조 → 제외된 소량 브라우저 검증. Gmail 브리핑 변경·대시보드·CTA 변경·AB 테스트·광고 attribution은 포함하지 않는다.

회원 가입 동의 버전 `2026-09-14-members`는 기존 회원 처리 목적을 위한 값이며 이번 분석에 대한 동의를 받았다는 증거로 재사용하지 않는다. 쿠키를 새로 만들지 않는다는 사실만으로 동의가 불필요하다고 판단하지 않는다. 운영 적용 승인 시 분석 처리 근거·방침 공지와 실제 시행일을 확인한다.

설계 근거: [Supabase 함수 권한](https://supabase.com/docs/guides/database/functions), [Supabase Cron](https://supabase.com/docs/guides/cron). 동의·방침 검토 시 [개인정보 포털](https://www.privacy.go.kr/front/case/list.do)의 공식 상담·안내를 참고한다.
