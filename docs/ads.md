# 소량 광고 배치

현재 `ads-config.js`는 비활성 상태입니다. 실제 게시자/광고 단위 번호가 코드에 입력되어 있지 않으므로
광고나 빈 광고 상자를 표시하지 않고 Google에 요청도 보내지 않습니다.

배치: `guide.html`의 장비 안내 뒤, `reading-sky.html`의 해설 본문 뒤에 각각 **한 자리**.
첫 화면·행성 지도·달력 조작부·게시판·약관·관측 노트 작성 도구에는 삽입하지 않습니다.
가로형 반응형 디스플레이 광고이며 광고를 메뉴나 추천 콘텐츠처럼 꾸미지 않습니다.

실제 도입 순서:

1. 애드센스에서 해당 사이트가 준비됨인지 확인하고 반응형 디스플레이 광고 단위를 만듭니다.
2. 애드센스의 **자동 광고를 끕니다**. 자동 광고는 광고 단위 코드로도 동작할 수 있으므로
   코드에 한 자리만 넣었다고 페이지의 광고 수가 반드시 한 개로 제한되는 것은 아닙니다.
   앵커·전면 광고도 사용하지 않습니다. 광고 크기 최적화의 동작도 계정에서 확인합니다.
3. 실제 게시자 ID와 광고 단위 ID를 `ads-config.js`에 넣습니다. ID 예시를 실제 값처럼 사용하지 않습니다.
4. 애드센스가 안내한 실제 `ads.txt` 내용을 저장소 루트에 추가합니다.
5. 개인정보처리방침의 ‘현재 광고 미송출’을 실제 사업자·처리 항목·쿠키·설정/거부 방법으로 갱신합니다.
   사이트가 적용받는 동의 요건과 Google의 지역별 동의 정책을 확인하고,
   필요한 지역의 Google 인증 CMP 등 동의 관리를 설정한 뒤 활성화합니다.
6. `enabled: true`로 변경하고 실제 모바일/PC 광고 크기와 콘텐츠 간격을 확인합니다.
   자체 광고를 클릭해서 시험하지 않습니다.

승인·수익은 보장되지 않습니다. 광고 슬롯 비활성 상태와 테스트 SDK를 이용한 동작을 검사하며,
개발 테스트에서는 운영 광고 요청을 보내지 않습니다.
스크립트는 두 가이드 경로만 허용하며, SDK 차단·실패 또는 `data-ad-status=unfilled` 응답 때 빈 광고 영역을 제거합니다.
GitHub·Supabase 연결 확인은 애드센스 계정 연결이나 사이트 승인 확인을 대신하지 않습니다.
