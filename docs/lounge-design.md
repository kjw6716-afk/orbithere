# 자유게시판 시각 개선

## 적용 범위

`lounge.html`과 `main.html#lounge`에 같은 배너, 공지, 검색, 목록 스타일을 적용합니다.
스타일은 `lounge-design.css`에 두고 `lounge-page` 또는 활성 패널의 `lounge-active`에 한정합니다.
다른 메뉴로 전환하면 메인 셸의 원래 스타일과 우주 이야기 안내 위치로 돌아갑니다.
홈, 공통 메뉴 생성 구간, 뉴스 데이터, 인증, DB 설정과 기존 URL은 유지합니다.

- 배너는 PC에서 최소 176px이며 내용이 많거나 화면이 좁으면 높이가 늘어납니다.
- 배너에는 제목·기존 소개·내 활동·글쓰기만 표시합니다. 공지 다음에 검색과 질문 필터를 둡니다.
- 목록과 본문·작성 폼은 단색 면입니다. 기존 첨부 사진이 있는 글에만 썸네일을 표시합니다.
- 실제 고정 공지와 20개 단위 목록 조회를 그대로 사용합니다. 글 수 표시는 불러온 항목 수이며 서비스 전체 통계로 바꾸지 않습니다.
- 빈 게시판, 검색 결과 없음, 내 활동 없음은 기존 안내와 동작을 유지하고 장식만 추가합니다. 불러오기 실패는 기존 오류·재시도로 표시합니다.
- 추천·인기 순위·회원 수·주제 태그를 추가하지 않습니다. 뉴스는 기존 출처·날짜·제목 링크를 유지합니다.

## 자산

배너는 홈의 `images/nebula-landing-{1200,1600,2000,2430}.{avif,webp}`를 재사용합니다.
AI 생성 이력과 실제 원본 크기 2430×1457은 [기존 자산 기록](nebula-and-otter.md)에 있습니다.
새 이미지 생성이나 외부 사진 도입은 없습니다. 이 자산을 실제 천체 관측 사진으로 표시하지 않습니다.
`picture`와 `srcset`으로 화면에 맞는 한 개 자산을 선택하며, CSS로 배너 안에서 잘라 표시합니다.
글자는 이미지에 포함되지 않은 HTML입니다. 장식 이미지는 빈 대체 텍스트를 사용합니다.

`images/orbit-conversation.svg`는 이번 변경에서 만든 별·궤도 벡터 장식입니다.
회원이나 활동 데이터를 표현하지 않으며 애니메이션이 없습니다.

뉴스 JSON에는 이미지 URL·이미지 크레딧·이용 조건이 없으므로 썸네일을 임의로 붙이지 않습니다.
향후 도입할 때는 기사에 맞는 이미지별 출처와 사용 조건을 기록해야 합니다.

## 확인할 동작

단독/임베드 진입, 공지 열기, 검색·초기화·질문 필터, 내 활동, 로그인 진입,
글쓰기·댓글·사진 첨부, 이전 글 더 보기, 상세에서 목록으로 돌아올 때 스크롤 복원을 확인합니다.
320·390·1440px와 넓은 화면에서 넘침 및 첫 게시글 노출을 검사합니다.
운영 데이터에 테스트 글이나 댓글을 작성하지 않고 기존 모의 서버 검사를 사용합니다.
