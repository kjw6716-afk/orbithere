# 부담 없이 시작하는 별빛 게시판

## 작성과 읽기

- 제목은 선택입니다. 비어 있으면 이야기의 첫 줄 중 첫 문장을 사용하며, 80 UTF-16 코드 단위에서 자릅니다. 이모지의 서로게이트 쌍은 나누지 않습니다. 본문은 기존 5,000자 제한을 유지합니다.
- 전체 게시판에서 시작한 글의 기본 분류는 기존 `free`입니다. 관측 후기·질문 등 분류별 작성 링크는 해당 분류를 유지합니다. 별도의 초보자 게시판은 만들지 않습니다.
- 첫 방문자도 먼저 본문을 쓸 수 있습니다. 제출할 때 같은 화면에서 닉네임을 정하며, 기존 2~12자·금지 문자 기준을 적용합니다. 닉네임은 기존 브라우저 키에 저장하고, 임베드의 상위 화면에는 출처를 검사하는 메시지로 변경을 알립니다.
- 관측 정보와 장비·촬영 정보는 기본으로 접힌 선택 영역입니다. 입력하지 않은 값을 추측하거나 현재 시각·위치로 채우지 않습니다. 맨눈·휴대폰도 관측 방법입니다.
- 선택 기록은 `posts.observation`에 본문과 분리해 저장합니다. 허용된 11개 키의 문자열만 받으며 각 값은 공백 제거 후 1~120자, 관측 방법은 지정된 값만 허용합니다. 빈 기록은 `{}`입니다.
- 기록이 있는 글은 기본 관측 정보를 표시하고 장비·촬영 기록은 접어 둡니다. 기존 글에 없는 정보를 꾸며 넣지 않습니다. 값은 DOM의 텍스트로 표시합니다.
- 관측 날짜·시각·대략적인 장소는 이용자가 직접 입력하는 공개 게시물 정보입니다. GPS·사진 EXIF에서 가져오지 않습니다. 사진의 축소·EXIF 제거·비공개 업로드·소유권 처리는 기존 흐름을 사용합니다.
- 실제 계정 등록·기기 간 계정 연결·가입 권유는 이번 변경에 포함하지 않습니다. 이메일을 받는 미작동 안내를 제품에 넣지 않습니다.

## 호환성과 배포

- 기존 `create_board_post`와 `board_version()=1`을 유지합니다. 기록 없이 쓰는 글은 기존 API를 사용합니다.
- 추가 기록이 있으면 `board_observation_version()`을 확인한 뒤 사진을 예약하고 `create_observation_post`로 원자적으로 저장합니다. 권한은 invoker이며 기존 작성자·도배 제한·사진·관리자 고정 트리거가 그대로 실행됩니다.
- 기존 UUID와 모든 기록 값을 비교해 응답 유실 후에도 한 번만 저장합니다. 불확실한 응답에서는 입력을 잠그고 같은 payload로 재시도합니다. 선택 기록을 조용히 버리지 않습니다.
- DB 마이그레이션을 먼저 적용하고 UI를 병합합니다. 구버전 DB에서 새 컬럼을 읽지 못하면 본문을 다시 읽어 기존 글은 열리게 합니다. 선택 기록의 저장 준비가 안 되어 있으면 입력을 보존하고 재시도를 안내합니다.
- 새 검증 함수는 별도 비공개 스키마에 두며 기존 내부 스키마의 접근 권한은 넓히지 않습니다. 새 컬럼은 공개 SELECT만 추가하며 UPDATE 권한을 부여하지 않습니다.
- 검색은 기존 제목·본문과 직접 입력한 선택 기록 값을 문자 그대로 찾습니다. 커서·고정 공지·조회수·목록 응답 구조를 유지합니다.

## 용어 설명과 근거

2026-09-13 기준, 다음 공식 자료와 대조한 짧은 설명 11개를 제공합니다. 한국어 풀이와 ‘돕’이라는 약칭 설명은 ORBIT 편집 표현이며 제조사가 한국어 약칭을 정의했다고 주장하지 않습니다.

- M13·구상성단: [NASA M13](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-13/)
- M42·성운: [NASA M42](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-42/)
- M57: [NASA M57](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-57/)
- 돕/돕소니안·경통·가대·경위대·아이피스/접안렌즈·구경: [Celestron 돕소니안 구조·광학계 설명](https://www.celestron.com/products/starsense-explorer-12-smartphone-app-enabled-dobsonian-telescope)

본문과 관측 기록에서 각 뜻의 첫 등장에만 설명 버튼을 붙입니다. 원래 글자를 유지하며 저장된 원문은 바꾸지 않습니다. 제목 링크·작성 입력·댓글에는 자동 삽입하지 않습니다. URL·이메일·긴 식별자·다른 단어의 일부는 제외합니다. ‘구경’은 숫자와 광학 단위가 뒤따를 때만 설명합니다. 아직 등록되지 않은 용어와 애매한 표현은 그대로 둡니다.

설명은 클릭·터치·키보드로 열리는 대화상자이며 원문 링크를 제공합니다. Escape와 닫기 버튼으로 닫으면 호출한 용어로 초점이 돌아옵니다. 실시간 AI 해석이나 외부 용어 조회 요청은 없습니다.
