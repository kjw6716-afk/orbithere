## 시간 정책

행성 도구는 기존 태양 계산식의 고도 −0.833° 교차로 도시별 일출·일몰을 찾는다. 일출 전에는 전날 저녁부터 진행된 밤을 유지하고, 일출 시각부터 그날 저녁~다음 새벽을 선택한다. 어두운 하늘의 관측 기준인 태양 고도 −6°와 행성 고도 5°는 유지한다. 추천 후보는 현재 시각 이후만 사용하며 현재 표본은 실제 시각을 사용한다. 일출 직전 남은 어두운 시간이 없으면 과거의 최적 시각을 추천하지 않는다.

일정 상태는 `[watchStart, watchEnd)`이다. 시작 전에는 예정, 시작 시각부터 진행 중, 종료 시각부터 종료다. `peakAt`은 알려진 극대·최대식만 담으며 상태 판정에 쓰지 않는다. 날짜만 알려진 극대는 `null`과 기존 `peakText`를 유지한다. D-day는 KST 달력 날짜 차이이며 카운트다운은 예정이면 시작까지, 진행 중이면 종료까지 표시한다.

유성우·보름달의 종료는 **기존 추천 밤의 안내 마감**이다(명시된 05:00 또는 06:00 KST). 실제 유성우 전체 활동 종료나 도시별 일출 예측을 뜻하지 않는다. 여러 밤을 안내하는 페르세우스자리 기간에는 사이의 낮도 포함되므로 관측은 안내된 밤 시간이라는 설명을 함께 둔다. 일식·월식은 전지구 반영 접촉 P1~P4를 사용하고 국내 관측 불가 표시를 유지한다.

## 검증

`node tests/astronomy.mjs`는 기존 천문 검사와 두 순수 시간 회귀 파일을 함께 실행한다. `node tests/render.mjs`는 기존 렌더 검사와 `time-render.mjs`의 고정 시각 브라우저 검사를 함께 실행한다. 기존 CI 진입점과 `npm test`에 모두 포함되며 별도 API나 운영 DB 접근이 필요하지 않다.

고정 fixture는 일출·일몰 전후, 자정, 새벽 2시, 오전 10시·11:59·정오·오후, 월말·연말, 8개 도시를 포함한다. 일정은 시작/종료 ±1ms와 정확한 시각, 극대 전후, 여러 밤, 국내 불가, 마지막 일정 종료를 검사한다. 브라우저에서는 KST·UTC·미국 시간대, 독립 페이지·실제 main iframe, 모바일, 열린 페이지의 시각 전환을 비교한다.

## 독립 천문 기준 표본

[JPL Horizons API](https://ssd-api.jpl.nasa.gov/doc/horizons.html)의 관측지 좌표와 `QUANTITIES=4`, `APPARENT=AIRLESS`를 사용했다. 서울·강릉·제주 × 7행성 × 5시각(2026-09-26 02/10/20시, 12-31 23:59, 2027-01-01 02시 KST)의 105표본을 대조했다. 같은 도시의 2026-06-21, 09-26, 12-31 일출·일몰도 태양 중심 −0.833° 교차로 비교했다. [관측량 정의](https://ssd.jpl.nasa.gov/horizons/manual.html#observer-table)

- 행성 고도 최대 차이 0.379°, 방위각 1.508°. 야간 관측 기준을 만족하는 38표본에서는 고도 0.377°, 방위각 0.484°.
- 일출 최대 차이 110.455초, 일몰 101.389초. KST 날짜 및 8방위 이름 불일치 0건.
- 제주 해왕성 12/31 23:59는 JPL +0.333° / ORBIT −0.046°로 지평선 위아래 부호가 다르지만 두 값 모두 기존 관측 기준 5°보다 낮다. 기존 근사식의 한계로 기록한다.
- 변경 전후 위치·밝기·달 계산식이 동일하고 비교 표본의 좌표도 동일하다. 기존 공식 변경은 없다. 독립 광도 수치 대조, 모든 날짜·도시의 정밀 검증, 실제 대기·지형·날씨 검증은 포함하지 않는다.
