Orbit 개인정보처리방침

닉네임과 게시물, 작성 권한을 어떻게 다루는지 안내합니다. 저장하는 정보와 지우는 방법을 함께 확인해 주세요.

시행일: 2026년 9월 14일 (직전 시행일: 2026년 9월 12일)
먼저 알아두세요

공개한 글은 다른 사람이 읽을 수 있어요. 브라우저 데이터를 지우기 전에 삭제할 글이 있는지 확인해 주세요.

처리하는 정보보관과 삭제브라우저 저장내 권리

1. 수집하는 정보

Orbit(orbithere.com, 이하 "서비스")은 가입 없이 읽고 익명으로 활동할 수 있으며, 선택적으로 이메일 회원 기능을 이용할 수 있습니다. 게시글을 열어 조회수를 집계하거나 글·댓글·리액션·신고를 처음 저장할 때 Supabase가 익명 인증 계정을 만들며, 다음 정보를 다룹니다.

닉네임

이용자가 직접 입력한 별칭

보관 위치 · 이용자 브라우저 저장소, 글 작성 시 데이터베이스

게시물

작성한 제목·내용·사진·댓글·리액션과 작성 시각. 선택해서 입력한 관측 시각·대략적인 장소·대상·방향·장비·촬영 정보도 글과 함께 공개됩니다.

보관 위치 · 데이터베이스·사진 저장소(Supabase)

방문 집계

날짜별 방문 횟수(숫자 하나)와, 하루 한 번만 세기 위한 임시 표시값. 실명·연락처와 연결한 방문 이력을 만들지 않습니다.

보관 위치 · 데이터베이스·사진 저장소(Supabase)

익명 작성자와 인증 세션

서버가 발급한 무작위 사용자 ID와 이 브라우저의 작성 권한을 증명하는 인증 세션. 직접 입력하는 실명·이메일·비밀번호는 없습니다.

보관 위치 · 사용자 ID는 Supabase 인증 계정과 글·댓글·리액션·신고에 저장됩니다. 인증 세션은 이용자 브라우저에 저장됩니다.

방문 집계용 기기 식별자

브라우저가 만든 무작위 식별값. 작성 권한을 증명하는 데 사용하지 않습니다.

보관 위치 · 브라우저 저장소. 방문 집계 서버에는 날짜와 섞은 축약값만 저장합니다.

익명 인증은 본인의 글·댓글 삭제, 리액션 중복 방지, 도배와 반복 신고 제한, 게시글 조회수 중복 방지에 사용합니다. 서버가 인증 세션을 검증하며, 닉네임이나 공개된 ID만으로는 삭제할 수 없습니다.

내 활동에서는 인증된 작성자 ID로 내가 쓴 글과 다른 사람의 글에 댓글을 남긴 대화를 찾습니다. 내 글의 댓글과 참여 이후 달린 다른 사람의 댓글 중, 화면에 나타난 댓글의 ID와 내 사용자 ID를 Supabase의 비공개 읽음 기록에 저장합니다. 이 기록은 새 답글 구분에만 사용하며 다른 이용자에게 공개하지 않습니다. 댓글 본문·닉네임·IP 주소·별도의 열람 시각은 읽음 기록에 추가하지 않습니다. 내 활동 확인만으로 새 익명 계정을 만들지 않으며 이메일·푸시 알림은 발송하지 않습니다.

삭제 후 반복 작성하는 도배를 막기 위해 글·댓글·신고의 작성자 ID, 대상 ID, 종류, 작성 시각을 비공개 제한 기록에 보관합니다. 이 기록에는 본문·닉네임·IP 주소를 추가로 저장하지 않습니다.

글·댓글에 연결된 무작위 작성자 ID는 공개 조회 결과에 포함될 수 있어 같은 작성자의 게시물을 연결해 볼 수 있습니다. 인증 세션은 공개하지 않습니다. 신고 내용은 운영자만 열람합니다.

게시글 조회수는 글을 열었을 때 같은 익명 인증 계정 기준으로 글마다 30분에 한 번 집계하며, 누적 숫자만 공개합니다. 사용자 ID·게시글 ID·마지막 집계 시각은 비공개 중복 방지 기록으로 보관합니다. 본문·닉네임·IP 주소를 이 기록에 추가 저장하지 않습니다. 인증이나 통계 연결에 실패해도 글은 읽을 수 있으며 조회수에는 반영되지 않을 수 있습니다.

방문 집계는 작성자 인증과 별도로 하루 한 번만 셉니다. 날짜별 방문 횟수와 임시 중복 방지값을 저장합니다.

이메일로 직접 문의하면 발신 이메일 주소와 이용자가 작성한 내용·첨부파일이 운영자의 Gmail로 전달되며 문의 확인과 답변에 사용됩니다. 이메일 문의는 공개 게시판에 게시되지 않습니다. 사이트에는 별도의 이메일 문의 입력 폼이 없으며, Gmail 버튼은 메일 작성 화면을 엽니다. 비밀번호·인증 정보·신분증은 보내지 마세요.

  • 공개 콘텐츠 열람과 익명 활동에는 이름, 이메일, 전화번호, GPS 위치 입력을 요구하지 않습니다. 이메일 회원 가입에는 이메일과 비밀번호가 필요합니다. 이용자가 게시글에 직접 입력한 정보는 다른 이용자에게 공개되므로 주의해 주세요.
  • Google Analytics 등 제3자 방문자 추적(analytics) 도구를 사용하지 않습니다. 방문 집계는 위 안내와 같이 날짜별 방문 횟수와 임시 중복 방지값을 자체 데이터베이스에 남기며, 광고용 이용자별 이동 경로를 만들지 않습니다. 게시글 조회수의 임시 중복 방지 기록은 아래와 같이 별도로 처리합니다.
  • 호스팅(GitHub Pages)·데이터베이스(Supabase) 사업자가 서비스 운영을 위해 접속 기록(IP 주소 등)을 자동 수집할 수 있으며, 이는 각 사업자의 개인정보처리방침을 따릅니다.

회원정보 수집·이용

이메일 회원 기능을 이용하는 경우 다음 정보를 처리합니다. 가입 없이 글을 읽거나 익명으로 활동하는 방법도 유지됩니다.

정보 목적·보관
이메일, 비밀번호의 해시값, 이메일 인증·계정 식별 정보 가입·로그인·비밀번호 재설정·작성 권한 확인. 탈퇴 완료 시 삭제합니다. 비밀번호는 인증을 위해 Supabase로 전송하며, 원문을 게시물 데이터베이스·브라우저 저장소에 보관하지 않습니다.
회원 닉네임, 가입 시각, 동의한 방침 버전, 이메일 연결 후 비밀번호 설정 여부 프로필 표시와 가입 동의 기록. 탈퇴 완료 시 삭제합니다.
출석 날짜·별빛 지급 사유·양·시각, 이벤트 식별값, 지급 운영자 식별값, 선택한 배지 레벨·배지 표시, 중복 보상 방지, 이벤트 지급 확인. 계정 탈퇴 시 개인별 지급 기록과 배지를 삭제합니다. 이벤트 자체의 이름·배점은 회원과 연결하지 않은 운영 기록으로 남을 수 있습니다.

닉네임·레벨·선택한 배지는 공개됩니다. 이메일, 개인별 출석·별빛 내역은 공개하지 않습니다. 운영자는 이벤트 지급에 필요한 회원 닉네임과 지급 내역을 확인할 수 있습니다.

만 14세 이상만 이메일 회원으로 가입할 수 있습니다. 수집·이용에 동의하지 않으면 이메일 회원 기능을 이용할 수 없으며, 공개 콘텐츠 열람은 가능합니다.

내 계정에서 닉네임을 수정하고 로그아웃하거나 회원 탈퇴를 할 수 있습니다. 탈퇴는 비밀번호 재확인 후 진행되며, 본인 글·댓글·사진·리액션·신고와 계정·별빛·배지를 삭제합니다. 내 글에 달린 다른 이용자의 댓글도 함께 삭제됩니다. 사진 삭제 등이 실패하면 처리가 완료될 때까지 추가 작성을 제한하고, 같은 계정에서 탈퇴를 다시 실행해 남은 삭제를 이어갑니다.

회원은 브라우저 데이터를 지워도 이메일로 다시 로그인해 활동을 이어갈 수 있습니다. 익명 계정은 기존 브라우저 인증 세션이 남아 있을 때 이메일을 연결해야 활동을 이어갈 수 있습니다. 다른 기존 계정으로 로그인하는 경우 익명 활동이 자동 합쳐지지 않습니다.

계정 인증 및 데이터베이스는 Supabase를 사용하며 현재 프로젝트의 데이터베이스 지역은 서울입니다. 이는 모든 인증메일·접속기록·지원 업무가 국내에서만 처리된다는 의미는 아닙니다. 가입 인증메일 발송 사업자와 관련 처리 내용은 공개 가입을 활성화하기 전에 이 방침에 추가합니다.

2. 이용 목적

  • 닉네임: 커뮤니티 내 작성자 표시
  • 내 활동·댓글 읽음 기록: 내가 쓴 글과 참여한 대화를 다시 찾고 아직 확인하지 않은 답글 표시
  • 게시물: 커뮤니티 서비스 제공(모든 이용자에게 공개 표시)
  • 익명 인증 계정: 본인 게시물 삭제 권한 확인, 리액션 중복 방지, 도배·중복 신고 방지. 방문 집계용 기기 식별자: 하루 방문 수 중복 집계 방지
  • 방문 집계: 서비스 이용 추세 확인(운영자만 열람). 광고·맞춤형 추천에 쓰지 않습니다

3. 보관 및 파기

  • 닉네임·인증 세션·방문 집계용 기기 식별자는 브라우저 데이터를 지우면 해당 브라우저에서 삭제됩니다. 익명 인증 세션을 잃으면 이전 글의 직접 삭제 권한을 복구할 수 없습니다. 이메일 회원은 다시 로그인할 수 있습니다.
  • 게시물의 작성자 연결값은 해당 게시물과 함께 삭제됩니다. Supabase의 익명 인증 계정은 브라우저 데이터를 지워도 자동 삭제되지 않으며, 운영자의 계정 정리 또는 삭제 요청 처리 시까지 보관됩니다.
  • 방문을 하루 한 번만 세기 위한 임시 표시값은 만들어진 지 4일이 지나면 그 다음 방문이 기록될 때 함께 삭제됩니다. 날짜별 방문 횟수(숫자)는 개인과 연결되지 않은 통계라 계속 보관합니다.
  • 게시물은 이용자가 직접 삭제하거나 운영자가 운영 정책에 따라 삭제할 때까지 보관됩니다.
  • 사진은 글당 최대 5장까지 올릴 수 있습니다. 일반 글쓰기 화면은 사진을 JPEG로 변환해 긴 변을 2,048픽셀 이하로 줄이고 EXIF 촬영 정보를 제거합니다. 사진 안에 보이는 주소·얼굴·차량번호 등은 자동으로 가리지 않습니다.
  • 게시 전 사진은 작성자와 운영자만 볼 수 있고, 글에 등록한 사진은 누구나 볼 수 있습니다. 글을 삭제하면 새 사진 다운로드가 차단됩니다. 이미 다른 사람이 내려받은 사본은 회수할 수 없습니다.
  • 글 삭제 시 연결된 사진 파일도 삭제를 시도합니다. 업로드 중단이나 삭제 오류로 남은 비공개 파일은 생성 후 하루가 지난 뒤 운영자가 정리합니다. 업로드 권한·도배 방지용 예약 기록은 1시간 동안 쓰이며, 하루가 지난 기록은 다음 사진 예약 때 삭제됩니다.
  • 도배 방지용 작성 기록은 게시물을 지워도 즉시 삭제되지 않습니다. 작성한 지 1시간이 지나면 다음 글·댓글·신고가 정상 저장될 때 함께 삭제되며, 해당 인증 계정 삭제 시에도 제거됩니다.
  • 조회수 중복 방지 기록은 30분이 지나면 이후의 정상 조회 요청에서 오래된 순으로 최대 500건씩 정리됩니다. 글 또는 인증 계정 삭제 시 연결된 기록도 삭제됩니다. 누적 조회수는 글 삭제 시 함께 삭제됩니다.
  • 댓글 읽음 기록은 해당 댓글 또는 인증 계정이 삭제될 때 함께 삭제됩니다. 글을 삭제하면 그 글의 댓글과 읽음 기록도 삭제됩니다. 브라우저 데이터를 지워도 서버의 읽음 기록은 자동 삭제되지 않으며, 익명 인증 세션을 잃으면 이전 내 활동·읽음 기록을 이어서 확인할 수 없습니다.
  • 서비스 개편으로 데이터 이전이나 삭제가 필요한 경우 대상과 시점을 가능한 한 미리 안내합니다.

4. 브라우저에 기억하는 정보

다음 정보를 이용 중인 브라우저에 저장해 다음 방문에도 이어서 이용할 수 있게 합니다. 브라우저의 ‘사이트 데이터 삭제’에서 지울 수 있어요.

  • 닉네임과 처음 이용한 시점 — 내 별칭과 이용 시작 시점을 화면에 표시합니다. 닉네임은 글·댓글을 작성할 때 게시물과 함께 서버에 저장됩니다.
  • 작성 권한을 유지하는 인증 정보 — 이 브라우저에서 내가 쓴 글과 댓글을 구분하고 삭제할 수 있도록 합니다. 조회수 중복 방지와 운영자 로그인 유지에도 사용합니다.
  • 방문 중복 집계 방지 정보 — 무작위 식별값과 마지막 집계 날짜로 하루에 여러 번 방문해도 중복해서 세지 않도록 합니다.
  • 직전 시작 이야기 — 첫 화면을 새로고침할 때 같은 이야기가 연속해서 먼저 나오지 않도록 현재 탭에 이야기 주소 하나를 기억합니다. 탭을 닫으면 사라지며 서버로 전송하지 않습니다. 저장이 차단된 브라우저에서는 무작위 순서만 적용됩니다.
  • 선택한 관측 도시 — 다음에도 같은 도시의 하늘을 보여줍니다. 목록에서 선택한 도시만 기억하며 GPS 위치를 수집하거나 선택한 도시를 서버에 전송하지 않습니다.

종료된 운세 기능에서 선택했던 별자리·띠 정보가 예전 브라우저에 남아 있을 수 있습니다. 현재는 읽거나 새로 저장하지 않으며, 사이트 데이터를 지우면 함께 삭제됩니다.

사이트 데이터를 지워도 서버에 올린 게시물과 익명 인증 계정은 자동 삭제되지 않습니다. 작성 권한도 사라질 수 있으므로, 지우고 싶은 게시물은 먼저 삭제해 주세요.

관측 가이드의 체크리스트는 저장하거나 서버로 보내지 않습니다. 종료된 관측 노트에서 이용자가 직접 저장했던 기록 한 건은 해당 브라우저에 남아 있을 수 있습니다. 기존 저장본 보관 안내에서 기록을 열어 복사·다운로드하거나 ‘기기 저장본 삭제’로 지울 수 있습니다. 기록은 자동으로 열거나 전송하지 않으며 새 기록을 저장하지 않습니다. 직접 내려받은 파일과 복사한 내용은 이용자가 보관·삭제합니다. 우주 이야기의 검색어는 현재 페이지에서만 사용하고 저장·전송하지 않습니다.

뉴스의 원문 링크를 누르면 해당 기관 사이트로 이동합니다. 제작자 문의의 Gmail 버튼을 누르면 Google의 메일 작성 화면으로 이동하며, 해당 서비스의 개인정보처리방침이 적용됩니다. 소개·문의 페이지를 읽기만 할 때에는 Gmail에 접속하거나 메일을 전송하지 않습니다.

게시판 검색어는 글을 찾기 위해 Supabase로 전송되고 현재 주소와 브라우저 방문 기록에 남을 수 있습니다. 검색어에는 개인정보나 인증 정보를 입력하지 마세요. 작성 중인 댓글은 페이지 안에서만 유지되며, 페이지를 닫거나 새로고침하면 사라집니다.
