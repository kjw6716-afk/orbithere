Orbit 개인정보처리방침

Orbit은 회원가입 없이 쓰는 서비스라 모으는 정보 자체가 아주 적어요. 그래도 무엇을, 왜, 어떻게 다루는지 투명하게 적어둡니다.

시행일: 2026년 9월 11일 (직전 시행일: 2026년 8월 3일)

1. 수집하는 정보

Orbit(orbithere.com, 이하 "서비스")은 이메일·비밀번호를 입력하는 가입 절차 없이 이용합니다. 글·댓글·리액션·신고를 처음 저장할 때 Supabase가 익명 인증 계정을 만들며, 다음 정보를 다룹니다.

항목내용저장 위치
닉네임이용자가 직접 입력한 별칭이용자 브라우저(localStorage), 글 작성 시 데이터베이스
게시물작성한 글·답(댓글)·리액션과 작성 시각데이터베이스(Supabase)
방문 집계날짜별 방문 횟수(숫자 하나)와, 하루 한 번만 세기 위한 임시 표시값. 누가 방문했는지는 남기지 않습니다.데이터베이스(Supabase)
익명 작성자와 인증 세션서버가 발급한 무작위 사용자 ID와 이 브라우저의 작성 권한을 증명하는 인증 세션. 직접 입력하는 실명·이메일·비밀번호는 없습니다.사용자 ID는 Supabase 인증 계정과 글·댓글·리액션·신고에 저장됩니다. 인증 세션은 이용자 브라우저에 저장됩니다.
방문 집계용 기기 식별자브라우저가 만든 무작위 UUID. 작성 권한을 증명하는 데 사용하지 않습니다.브라우저 저장소. 방문 집계 서버에는 날짜와 섞은 축약값만 저장합니다.

익명 인증은 본인의 글·댓글 삭제, 리액션 중복 방지, 도배와 반복 신고 제한에 사용합니다. 서버가 인증 세션을 검증하며, 닉네임이나 공개된 ID만으로는 삭제할 수 없습니다.

글·댓글에 연결된 무작위 작성자 ID는 공개 조회 결과에 포함될 수 있어 같은 작성자의 게시물을 연결해 볼 수 있습니다. 인증 세션은 공개하지 않습니다. 신고 내용은 운영자만 열람합니다.

방문 집계는 작성자 인증과 별도로 하루 한 번만 셉니다. 날짜별 방문 횟수와 임시 중복 방지값을 저장합니다.

  • 이름, 이메일, 전화번호, GPS 위치를 입력하도록 요구하지 않습니다. 이용자가 게시글에 직접 입력한 정보는 다른 이용자에게 공개되므로 주의해 주세요.
  • Google Analytics 등 제3자 방문자 추적(analytics) 도구를 사용하지 않습니다. 방문 집계는 위 표와 같이 날짜별 숫자만 자체 데이터베이스에 남기며, 이용자별 방문 이력이나 이동 경로는 만들지 않습니다.
  • 호스팅(GitHub Pages)·데이터베이스(Supabase) 사업자가 서비스 운영을 위해 접속 기록(IP 주소 등)을 자동 수집할 수 있으며, 이는 각 사업자의 개인정보처리방침을 따릅니다.

2. 이용 목적

  • 닉네임: 커뮤니티 내 작성자 표시
  • 게시물: 커뮤니티 서비스 제공(모든 이용자에게 공개 표시)
  • 익명 인증 계정: 본인 게시물 삭제 권한 확인, 리액션 중복 방지, 도배·중복 신고 방지. 방문 집계용 기기 식별자: 하루 방문 수 중복 집계 방지
  • 방문 집계: 서비스 이용 추세 확인(운영자만 열람). 광고·맞춤형 추천에 쓰지 않습니다

3. 보관 및 파기

  • 닉네임·인증 세션·방문 집계용 기기 식별자는 브라우저 데이터를 지우면 해당 브라우저에서 삭제됩니다. 인증 세션을 잃으면 이전 글의 직접 삭제 권한을 복구할 수 없습니다.
  • 게시물의 작성자 연결값은 해당 게시물과 함께 삭제됩니다. Supabase의 익명 인증 계정은 브라우저 데이터를 지워도 자동 삭제되지 않으며, 운영자의 계정 정리 또는 삭제 요청 처리 시까지 보관됩니다.
  • 방문을 하루 한 번만 세기 위한 임시 표시값은 만들어진 지 4일이 지나면 그 다음 방문이 기록될 때 함께 삭제됩니다. 날짜별 방문 횟수(숫자)는 개인과 연결되지 않은 통계라 계속 보관합니다.
  • 게시물은 이용자가 직접 삭제하거나 운영자가 운영 정책에 따라 삭제할 때까지 보관됩니다.
  • 베타 기간 중 서비스 개편으로 데이터가 일괄 초기화될 수 있습니다.

4. 브라우저 저장소(localStorage) 사용

브라우저에는 아래 설정과 인증 세션을 저장합니다. 글을 작성할 때 닉네임과 인증 정보가 서버로 전달되며, 브라우저 설정에서 로컬 저장값을 지울 수 있습니다.

  • orbit_nickname — 닉네임
  • orbit_joindate, orbit_jointime — 궤도 진입 시점
  • orbit_device_id — 방문 집계용 무작위 UUID. 이전 버전에서는 게시물 소유권에도 사용했지만 보안 업데이트 이후에는 사용하지 않습니다
  • sb-unwxpuvfqyjhgrcrmuhu-auth-token — Supabase 인증 세션(접근·갱신 토큰과 사용자 ID). 익명 작성자와 운영자 로그인에 사용합니다. 서버 주소를 변경하면 키의 프로젝트 부분도 바뀝니다
  • orbit_visit_day — 방문 수를 마지막으로 센 날짜. 같은 날 페이지를 여러 번 열 때 불필요한 요청을 보내지 않기 위한 값입니다
  • orbit_place — «오늘 밤 행성» 페이지에서 고른 관측 도시(예: seoul). 다음 방문에도 같은 도시로 계산해 보여주기 위한 값이며, 목록에 있는 도시 이름 외의 정보(실제 위치·GPS)는 담기지 않습니다. 서버로 보내지 않습니다

지난 버전에서 쓰던 orbit_zodiac, orbit_animal(운세 페이지에서 고른 별자리·띠)이 브라우저에 남아 있을 수 있습니다. 해당 기능을 내리면서 더 이상 저장하거나 읽지 않으며, 브라우저 데이터를 지우면 함께 삭제됩니다.

수집한 정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 서비스 운영을 위해 아래 인프라를 이용합니다.

6. 광고에 관한 안내

향후 서비스에 광고(Google AdSense 등 제3자 광고 서비스)가 게재될 수 있습니다. 이 경우 광고 사업자는 맞춤 광고 제공을 위해 쿠키를 사용할 수 있으며, 이용자는 Google 광고 설정에서 맞춤 광고를 관리하거나 거부할 수 있습니다. 광고 도입 시 이 방침을 갱신해 고지합니다.

7. 이용자의 권리

  • 보안 업데이트 이후 작성한 글·댓글은 작성 당시 인증 세션이 남아 있는 브라우저에서 직접 삭제할 수 있습니다. 이전 기기 ID 방식으로 작성한 글은 소유권을 안전하게 확인할 수 없어 운영자에게 삭제를 요청해야 합니다.
  • 브라우저 데이터를 삭제하면 닉네임과 인증 세션, 방문 집계용 기기 식별자가 함께 사라집니다. 다만 이미 올린 게시물은 그대로 남으며, 삭제 권한이 사라지므로 지우고 싶은 글은 미리 삭제하시거나 아래 경로로 요청해 주세요.
  • 기타 삭제 요청이나 문의는 글 남기기를 통해 남겨주세요.
